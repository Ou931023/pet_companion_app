# CR-0109 iPhone 語言切換驗收

日期：2026-09-22。狀態：尚未執行實機驗收。

自動測試驗證命令辨識、狀態同步與失敗處理，不證明實際台語發音品質。
本輪未更新手機安裝檔；測試前須確認安裝的是含 CR-0109 修正的新 build。
測試使用自己的測試帳號，不輸入真實住民資料，不要求發送照護通知或控制設備。

## 操作與預期

| 操作 | 預期 |
| --- | --- |
| 開啟 App，以國語聊兩句 | 每輪只回覆一次；說完能開始下一輪，字幕不被切換清除 |
| 說「幫我設定成台語」，下一輪問「你食飽未」 | 偏好變為台語；下一輪使用台語，不能只口頭答應而設定沒變 |
| 在台語模式說「好的」，再繼續台語聊天 | 不因短暫國語或辨識結果切回國語 |
| 說「請用國語跟我說話」 | 下一輪恢復國語，不必關掉 App |
| 說「我想聽台語歌」或「不要改成台語」 | 不變更聊天語言；音樂流程與語言設定分開 |
| 設定 → 看與聽 → 聊天語言，手動改成台語 | 顯示更新中／已更新；既有連線下一輪採用台語 |
| 國語、台語快速來回選擇 | 最後一次選擇生效，不被較晚收到的舊更新覆蓋 |
| 收音途中手動切換語言 | 不永久靜音或轉圈；當下句子不要求中途換語言，後續回覆採最新設定 |
| 切換時暫時關閉網路，再恢復並按麥克風 | 不假稱成功；能看到白話失敗或待重試狀態，恢復後可重試 |
| 打字傳送「今天心情很好」，同時有背景分析 | 訊息實際送出且只回覆一次，不是僅留下使用者氣泡 |
| 切到背景再回 App，繼續同一語言聊天 | 不出現舊語言回覆、重複播報或卡在收音／回覆中 |
| 登出後換另一測試帳號 | 不沿用前一帳號尚未完成的語言更新或對話 |

## 紀錄與放行

記錄 App build／commit、iOS 版本、Wi-Fi 或行動網路、上述各項通過／失敗。
若失敗，記錄使用句子、發生時的語言選項與畫面狀態即可；不要附帳號權杖、金鑰或住民私密對話。

必須分開記錄：命令有辨識、服務確認套用、下一輪實際語言、自然度、字幕與聲音。
「聊天語言已更新」只代表設定同步成功，不保證模型每句的發音或用詞正確。
若有無法恢復的靜音、轉圈、打字丟失、跨帳號套用或反覆切回錯誤語言，不放行此版本上架。
